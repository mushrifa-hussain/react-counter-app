# React Counter App

A simple and beginner-friendly Counter App built using React and the `useState` Hook.

## Features

- Increase counter value
- Decrease counter value
- Clean and minimal UI
- Built with React functional components
- Uses React Hooks (`useState`)

## Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/react-counter-app.git
```

2. Open the project folder

```bash
cd react-counter-app
```

3. Install dependencies

```bash
npm install
```

4. Start the development server

```bash
npm run dev
```

## How It Works

The application uses React's `useState` Hook to store and update the counter value.

- Clicking the `+` button increases the count
- Clicking the `-` button decreases the count
